
# 🔚 Finally Statement

This Java program demonstrates the use of the `finally` statement in exception handling.

The program accepts two numbers from the user and performs division. If the user tries to divide a number by zero, the exception is handled using a `catch` block.

The `finally` block executes regardless of whether an exception occurs or not.

## ⚙️ How It Works

1. Accepts two numbers from the user.
2. Performs division inside a `try` block.
3. Handles division by zero using `ArithmeticException`.
4. Displays an error message if an exception occurs.
5. Executes the `finally` block in every situation.
6. Displays a program completion message.

## 📚 Concepts Used

- Exception Handling
- `try` Block
- `catch` Block
- `finally` Statement
- `ArithmeticException`
- Scanner Class
