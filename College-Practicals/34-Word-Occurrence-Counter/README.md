# 🔍 Word Occurrence Counter

This Java program reads a text and counts all occurrences of a particular
word entered by the user.

## ⚙️ How It Works

1. Accepts a text from the user.
2. Accepts the word to be searched.
3. Uses `substring()` to extract portions of the text.
4. Uses `equals()` to compare each extracted word with the search word.
5. Increases the counter whenever a matching word is found.
6. Displays the total number of occurrences.

## 📚 Concepts Used

- String Class
- `substring()`
- `equals()`
- `length()`
- `for` Loop
- Counter Variable
- Scanner Class
- User Input
- Console Output

## 🖥️ Sample Output

Enter a text: java is easy and java is powerful
Enter word to search: java
