# 👨‍💼 Abstract Class & Abstract Method

This Java program demonstrates the implementation of an **abstract class** and an **abstract method** using an employee salary calculation example.

## ⚙️ How It Works

1. Accepts employee name and basic salary from the user.
2. Creates a `FullTimeEmployee` object.
3. Displays the employee details.
4. Calculates the net salary by implementing the abstract method.

## 📚 Concepts Used

- Abstract Class
- Abstract Method
- Inheritance
- Method Overriding
- Constructors
- `super()` Keyword
- Classes & Objects
- Scanner Class
- User Input
- Console Output
