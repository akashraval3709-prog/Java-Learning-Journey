# 📚 Stack Class Methods

This Java program demonstrates the commonly used methods of the `Stack` class
using a simple book management example.

## ⚙️ How It Works

1. Accepts book names from the user.
2. Stores the books in a Stack.
3. Uses `push()` to add books.
4. Uses `peek()` to view the top book.
5. Uses `search()` and `contains()` to find a book.
6. Adds another book using `push()`.
7. Removes the top book using `pop()`.
8. Checks the stack size and empty status.
9. Uses `clear()` to remove all books from the Stack.

## 📚 Concepts Used

- Stack Class
- LIFO (Last In, First Out)
- `push()`
- `pop()`
- `peek()`
- `search()`
- `contains()`
- `size()`
- `empty()`
- `clear()`
- Scanner Class
- User Input
- Console Output
