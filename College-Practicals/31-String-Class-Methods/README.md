# 🔤 String Class Methods

This Java program demonstrates various built-in methods of the `String` class
for performing common string manipulation and searching operations.

## ⚙️ How It Works

1. Accepts a full name from the user.
2. Accepts a word to search from the user.
3. Finds the length of the string.
4. Converts the string into uppercase and lowercase.
5. Demonstrates `charAt()` to access characters.
6. Uses `contains()` to search for text.
7. Uses `startsWith()` and `endsWith()` for string checking.
8. Uses `replace()` to replace characters or spaces.
9. Uses `substring()` to extract part of the string.
10. Uses `trim()` to remove unnecessary spaces.

## 📚 Concepts Used

- String Class
- `length()`
- `toUpperCase()`
- `toLowerCase()`
- `charAt()`
- `contains()`
- `startsWith()`
- `endsWith()`
- `replace()`
- `substring()`
- `trim()`
- Scanner Class
- User Input
- Console Output
