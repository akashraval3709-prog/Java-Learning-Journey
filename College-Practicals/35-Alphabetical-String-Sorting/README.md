# 35 - Alphabetical String Sorting

## 📌 Description

This program sorts a list of strings in **alphabetical order**.

It compares the strings and arranges them from **A to Z**.

### Example

**Input:**

```text
Banana
Apple
Mango
Orange
```

**Output:**

```text
Apple
Banana
Mango
Orange
```

---

## 🎯 Concepts Covered

* String handling
* Arrays / List of strings
* Alphabetical order
* String comparison
* Sorting
* Loops
* Conditional statements

---

## 🧠 How It Works

1. Take multiple strings as input.
2. Compare the strings with each other.
3. If a string comes after another string alphabetically, swap their positions.
4. Continue the comparison until all strings are sorted.
5. Display the sorted strings.

---

