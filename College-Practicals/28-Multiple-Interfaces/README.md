# 📱 Multiple Interfaces

This Java program demonstrates the implementation of **multiple interfaces** using a SmartPhone example.

The `SmartPhone` class implements both the `Camera` and `MusicPlayer` interfaces. It provides its own implementation for taking photos and playing music.

## ⚙️ How It Works

1. Creates a `Camera` interface with the `takePhoto()` method.
2. Creates a `MusicPlayer` interface with the `playMusic()` method.
3. `SmartPhone` implements both interfaces.
4. Accepts phone name and song name from the user.
5. Creates a SmartPhone object.
6. Performs photo and music operations.
