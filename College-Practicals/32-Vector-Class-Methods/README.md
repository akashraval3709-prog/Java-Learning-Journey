# 📦 Vector Class Methods

This Java program demonstrates the commonly used methods of the `Vector` class
using a simple product management example.

## ⚙️ How It Works

1. Accepts product names from the user.
2. Stores the products in a Vector.
3. Adds a new product using `addElement()`.
4. Displays the first and last products.
5. Displays the Vector size and capacity.
6. Searches for a product using `contains()` and `indexOf()`.
7. Removes a product from the Vector.
8. Updates an existing product using `set()`.
9. Checks whether the Vector is empty.

## 📚 Concepts Used

- Vector Class
- `add()`
- `addElement()`
- `size()`
- `capacity()`
- `firstElement()`
- `lastElement()`
- `contains()`
- `indexOf()`
- `remove()`
- `set()`
- `isEmpty()`
- Scanner Class
- User Input
- Console Output
