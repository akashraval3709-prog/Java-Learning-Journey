# 🧮 Math Class Methods

This Java program demonstrates the use of various built-in methods of the
`Math` class to perform mathematical calculations.

## ⚙️ How It Works

1. Accepts two numbers from the user.
2. Uses `Math.max()` to find the maximum value.
3. Uses `Math.min()` to find the minimum value.
4. Uses `Math.abs()` to find the absolute value.
5. Uses `Math.sqrt()` to calculate the square root.
6. Uses `Math.pow()` to calculate the power.
7. Uses `Math.round()` to round a number.
8. Uses `Math.ceil()` to find the upper integer value.
9. Uses `Math.floor()` to find the lower integer value.

## 📚 Concepts Used

- Math Class
- `Math.max()`
- `Math.min()`
- `Math.abs()`
- `Math.sqrt()`
- `Math.pow()`
- `Math.round()`
- `Math.ceil()`
- `Math.floor()`
- Scanner Class
- User Input
- Console Output
