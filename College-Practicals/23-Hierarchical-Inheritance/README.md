# 🏦 Hierarchical Inheritance

This Java program demonstrates the concept of **Hierarchical Inheritance**. Both the `SavingsAccount` and `CurrentAccount` classes inherit the properties and methods of the `BankAccount` class.

## ⚙️ How It Works

1. Accepts details for a Savings Account.
2. Calculates the yearly interest using the interest rate.
3. Accepts details for a Current Account.
4. Displays the overdraft limit for the current account.
5. Reuses the common account information inherited from the `BankAccount` class.
