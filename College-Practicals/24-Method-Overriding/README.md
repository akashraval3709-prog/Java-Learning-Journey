# 🔄 Method Overriding

This Java program demonstrates the concept of **Method Overriding**. The `Circle` class overrides the `calculateArea()` method of the `Shape` class to provide its own implementation.

## ⚙️ How It Works

1. Accepts the radius of a circle from the user.
2. Creates a `Circle` object.
3. Overrides the `calculateArea()` method of the parent class.
4. Calculates and displays the area of the circle.
