# ⚠️ Exception Handling using Try-Catch

This Java program demonstrates exception handling using the `try` and `catch`
blocks.

The program calculates the average marks of a student. If the user enters
`0` as the number of subjects, an `ArithmeticException` occurs because a
number cannot be divided by zero.

## ⚙️ How It Works

1. Accepts the total marks from the user.
2. Accepts the number of subjects.
3. Calculates the average marks.
4. The calculation is placed inside a `try` block.
5. If the number of subjects is `0`, an `ArithmeticException` occurs.
6. The `catch` block handles the exception and displays an error message.

## 📚 Concepts Used

- Exception Handling
- `try` Block
- `catch` Block
- `ArithmeticException`
- Scanner Class
- User Input
- Arithmetic Operators
- Console Output
