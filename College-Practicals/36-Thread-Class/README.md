# 🧵 Thread Class

This Java program demonstrates how to create and execute multiple threads by extending the `Thread` class.

## ⚙️ How It Works

1. Creates a custom `TaskThread` class that extends the `Thread` class.
2. Accepts a task name and number of iterations from the user.
3. Overrides the `run()` method to define the task performed by the thread.
4. Creates multiple thread objects for different tasks.
5. Starts each thread using the `start()` method.
6. Each thread executes independently and displays its progress.
7. Uses `Thread.sleep()` to simulate a small delay between task executions.
8. Demonstrates how multiple threads can run concurrently.
